Airnobe `v0.1.0` 是首个公开 Windows 测试版本。

## 主要功能

- 本地 EPUB 书库、批量选择和拖放导入、完整哈希查重及原书导出。
- 中日对照、纯中文和纯日文阅读，保留出版社 ruby。
- 辅助振假名与片假名罗马音，可通过快捷键独立切换。
- 虚拟连续滚动、目录、阅读进度恢复、书签和全键盘操作。
- 浅色／深色主题、五色自定义主题、托盘、全局显示快捷键和开机静默启动。
- 全新书库自动加入中日双语教程《Airnobe Start》。

## 下载与安装

- 支持 Windows 10/11 x64，仅提供 NSIS 安装器。
- 这是未签名的测试版本，Windows SmartScreen 可能显示未知发布者警告。运行前请先核对下方 SHA-256。
- 安装器按当前用户安装，无需管理员权限。
- 暂无自动更新；以后发布新版时，请从 GitHub Releases 下载并覆盖安装。

校验安装器：

```powershell
Get-FileHash .\Airnobe_0.1.0_x64-setup.exe -Algorithm SHA256
```

结果应与同一 Release 中的 `SHA256SUMS.txt` 完全一致。

## 本地数据

正式桌面版的书库保存在主程序同目录的 `AirnobeLibrary/`。覆盖安装不会清除书库；卸载程序也会保留该目录，重新安装后可继续使用。重要书籍仍建议自行备份。

## 已知限制

- 仅支持本地、无 DRM EPUB，不负责移除 DRM。
- 程序生成的注音用于辅助阅读，不保证达到出版级准确率。
- 当前仅支持 Windows x64，没有便携版、移动端或自动更新器。
- 安装器尚未进行商业代码签名。
