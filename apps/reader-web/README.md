# Airnobe Reader Web

本地 EPUB 阅读原型。

## 运行

在仓库根目录安装依赖并启动：

```text
npm install
npm run reader
```

打开终端显示的本地地址后会进入三栏书库，可通过文件选择器或从窗口外拖放一次导入多个 EPUB，并按收藏状态筛选、阅读或导出原书。书库索引保存在 `AirnobeLibrary/library.json`，每本书位于 `AirnobeLibrary/books/<library-book-id>/`，其中保存原始 `source.epub`、最终阅读数据，以及日文派生书的 `base.snapshot.json.gz`。旧 `base/`、`furigana/` 缓存不会自动迁移或删除。

书库列表双击继续阅读；选中书籍后按 `Space`、`Enter` 或右键打开继续阅读、从头开始、修改状态、导出和删除菜单。继续阅读恢复上次位于视口顶部的有效块并将其顶部对齐，从头开始忽略旧位置。

再次导入完全相同且格式为当前版本的 EPUB 时会自动忽略；旧格式记录会自动重建并保留书库状态。书名与作者或 OPF 标识相同但文件不同的书会提示忽略、替换或作为新书加入，操作可应用到后续同类冲突。批量转换逐本执行，部分失败不会回滚已完成项目。替换仅在新结果完整验证后生效。导入完成后停留在书库并选中最后一本成功书籍。

书库详情仅显示封面和书籍信息；重新导入不再提供界面入口。删除经二次确认后同时移除阅读数据和保存的原始 EPUB。

## 阅读控制

- `1`：显示或隐藏对应日文；出版社原生 ruby 随日文显示。
- `2`：同时显示或隐藏 `origin: "reused"` 与 `origin: "generated"` 的辅助注音。
- `3`：显示或隐藏仅标在片假名词上的改良赫本式罗马音。
- `W` / `S`：以下方可见单位为基准，按全局回退/快进段数移动并对齐底部。
- `E` / `F`：以上方可见单位为基准，按全局回退/快进段数移动并对齐顶部。
- `A` / `D`：向上或向下切换一个完整视口高度；右键菜单可选择是否使用淡入淡出。
- `Q`：打开或关闭左右并列阅读侧栏。
- 右键：同样切换阅读侧栏。

日文、程序振假名和片假名罗马音互相独立，`1/2/3` 会立即保存全局显示状态。配对日文以短暂淡入淡出和高度过渡显示或隐藏，系统减少动态效果时瞬时完成。从 EPUB 导入时会自动生成 P0.5 派生书。

文本块和块级图片都可导航；分隔符与 EPUB 空段跳过。段数只计文本块，但图片是硬停靠点。“回退/快进段数”默认为 2、范围 1–10。十项快捷键在独立窗口重新绑定，使用物理键位，并支持一个 `Ctrl`、`Alt` 或 `Shift` 附加键。返回书库仅使用侧栏按钮。设置保存在 `AirnobeLibrary/user.json`。

书库、阅读侧栏和浮层可用 WASD 或方向键移动焦点，`Space` 或 `Enter` 确认，`Escape` 取消；同时保留正文 W/S/E/F/A/D 阅读快捷键。数值输入使用 Enter 提交、Escape 恢复，输入和快捷键录制期间暂停空间导航。

阅读进度自动保存到每本书的 `reading-state.json`。继续阅读时恢复视口顶部所在的有效块，并把该块顶部统一对齐阅读区顶部；不复刻退出时段内的像素偏移。树形目录高亮当前章节；书库右侧详情显示百分比和章节。进度不会改变书库最近更新排序或收藏状态。

书库设置只管理主题；阅读侧栏管理主题和排版与样式，快捷键使用独立窗口。主题按浅色、深色或系统模式只显示当前有效类型，并分别记忆亮暗主题。主题 v2 可通过复制 AI 提示词后从剪贴板导入，旧 v1 主题仍可读取。字号、注音字号、400/600/800 字重、段内间距、段落间距、栏宽、日文透明度和导航段数即时预览并保持当前阅读块；日文引用线和左侧进度条均可关闭。原生注音保持金色，其余注音继承日文正文颜色。

当前版本按 readingOrder 虚拟连续阅读，仅维护桌面端。桌面封装属于 P2。
