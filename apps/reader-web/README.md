# Airnobe Reader Web

本地 EPUB 阅读原型。

## 运行

在仓库根目录安装依赖并启动：

```text
npm install
npm run reader
```

打开终端显示的本地地址后会进入三栏书库，可导入 EPUB、按收藏状态筛选、编辑备注、阅读或导出原书。书库索引保存在 `AirnobeLibrary/library.json`，每本书位于 `AirnobeLibrary/books/<library-book-id>/`，其中保存原始 `source.epub`、最终阅读数据，以及日文派生书的 `base.snapshot.json.gz`。旧 `base/`、`furigana/` 缓存不会自动迁移或删除。

再次导入完全相同且格式为当前版本的 EPUB 时不会重新转换；旧格式记录会自动重建并保留书库状态。书名与作者或 OPF 标识相同但文件不同的书会提示替换、另存或取消。替换仅在新结果完整验证后生效。导入成功后停留在书库并选中新书。阅读器右键菜单只保留阅读控制和返回书库；导入与导出位于书库界面。

## 阅读控制

- `Q`：显示或隐藏对应日文；出版社原生 ruby 随日文显示。
- `E`：同时显示或隐藏 `origin: "reused"` 与 `origin: "generated"` 的辅助注音。
- `Z`：显示或隐藏仅标在片假名词上的改良赫本式罗马音。
- `W` / `S`：以下方可见单位为基准，按全局回退/快进段数移动并对齐底部。
- `R` / `F`：以上方可见单位为基准，按全局回退/快进段数移动并对齐顶部。
- `A` / `D`：向上或向下切换一个完整视口高度；右键菜单可选择是否使用淡入淡出。
- `1`：打开或关闭阅读菜单。
- `2`：打开或关闭树形目录侧栏。
- 右键：同样打开阅读菜单。

日文、程序振假名和片假名罗马音互相独立，换书后都恢复为关闭。从 EPUB 导入时会自动生成 P0.5 派生书。

文本块和块级图片都可导航；分隔符跳过。段数只计文本块，但图片是硬停靠点。右键菜单中的“回退/快进段数”默认为 2。十一项默认快捷键都可点击键帽重新绑定，使用物理键位，并支持一个 `Ctrl`、`Alt` 或 `Shift` 附加键。翻页淡入淡出默认关闭。设置保存在 `AirnobeLibrary/user.json`。

书库、阅读菜单、目录和确认浮层可用 `W/S/A/D` 移动焦点、`Space` 确认。`W/S` 在当前区域首尾循环，`A/D` 不循环；输入框和快捷键录制期间暂停空间导航。鼠标、Tab 与 Enter 保持可用。

阅读进度自动保存到每本书的 `reading-state.json`，再次打开时恢复到上次块及视口偏移。树形目录高亮当前章节；书库右侧详情显示百分比和章节。进度不会改变书库最近更新排序或收藏状态。

当前版本按 readingOrder 虚拟连续阅读，仅维护桌面端。桌面封装属于 P2。
