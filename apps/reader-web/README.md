# Airnobe Reader Web

本地 EPUB 阅读原型。

## 运行

在仓库根目录安装依赖并启动：

```text
npm install
npm run reader
```

打开终端显示的本地地址后会进入三栏书库，可通过文件选择器、从窗口外拖放或标题栏的「轻小说机翻机器人」入口导入 EPUB，并按收藏状态筛选、阅读或导出原书。机器人入口接受 `n.novelia.cc/novel/<provider>/<novel>` 小说主页，固定下载中日、Sakura→GPT 优先、EPUB、中文文件名的现有翻译，然后进入同一查重和转换队列；它不会创建新的翻译任务。书库索引保存在 `AirnobeLibrary/library.json`，每本书位于 `AirnobeLibrary/books/<library-book-id>/`，其中保存原始 `source.epub`、最终阅读数据，以及日文派生书的 `base.snapshot.json.gz`。旧 `base/`、`furigana/` 缓存不会自动迁移或删除。

书库列表双击继续阅读；选中书籍后按 `Space`、`Enter` 或右键打开继续阅读、从头开始、修改状态、导出和删除菜单。继续阅读恢复上次位于视口顶部的有效块及其真实段内偏移，从头开始忽略旧位置。

再次导入完全相同且格式为当前版本的 EPUB 时会自动忽略；旧格式记录会自动重建并保留书库状态。书名与作者或 OPF 标识相同但文件不同的书会提示忽略、替换或作为新书加入，操作可应用到后续同类冲突。批量转换逐本执行，部分失败不会回滚已完成项目。替换仅在新结果完整验证后生效。导入完成后停留在书库并选中最后一本成功书籍。

书库详情仅显示封面和书籍信息，选中、取消与换书均使用完整交叉淡化，慢加载封面会在就绪后独立淡入；重新导入不再提供界面入口。删除经二次确认后同时移除阅读数据和保存的原始 EPUB。

## 阅读控制

- `1`：切换日文；出版社原生 ruby 随日文显示。
- `2`：切换 `origin: "reused"` 与 `origin: "generated"` 的辅助振假名。
- `3`：切换仅标在片假名词上的改良赫本式罗马音。
- `W` / `S`：以下方可见单位为基准，按全局滚动段数移动并对齐底部。
- `Z` / `X`：以上方可见单位为基准，按全局滚动段数移动并对齐顶部。
- `A` / `D`：向上或向下切换一个完整视口高度；右键菜单可选择是否使用淡入淡出。
- `Q`：打开或关闭左右并列阅读侧栏。
- `F`：切换全屏。
- `E`：在书库与最后阅读界面之间切换；离开阅读时先保存当前位置。
- `C`：为视口顶部的文本或图片添加书签。
- 右键：同样切换阅读侧栏。
- `F11` / `Alt+Enter`：切换全屏；浏览器开发版使用 Fullscreen API。

日文、程序振假名和片假名罗马音互相独立，`1/2/3` 会立即保存全局显示状态。日文开启时先展开 160ms、再淡入 180ms；关闭时先淡出 360ms、再收缩 320ms，并在全过程保持阅读锚点。两类程序注音继续使用 160ms／180ms 的原有阶段时间；快速重复切换从当前阶段反向，系统减少动态效果时瞬时完成。从 EPUB 导入时会自动生成 P0.5 派生书。

文本块和块级图片都可导航；分隔符与 EPUB 空段跳过。段数只计文本块，但图片是硬停靠点。“滚动段数”默认为 2、范围 1–10。十三项阅读快捷键在“阅读导航／显示与应用”双栏窗口重新绑定，使用物理键位，并支持一个 `Ctrl`、`Alt` 或 `Shift` 附加键；Backspace 清空当前绑定，重复组合键会交换两个动作的绑定。默认 `1/2/3` 切换日文、振假名和罗马音，`Z/X` 从顶部回退／快进，`W/S` 从底部回退／快进，`A/D` 翻页，`Q` 切换侧栏，`F` 全屏，`C` 添加书签，`E` 切换书库／阅读界面。`F11` 和 `Alt+Enter` 继续作为固定全屏入口。设置保存在 `AirnobeLibrary/user.json`。

书库、阅读侧栏和浮层可用 WASD 或方向键移动焦点，`Space` 或 `Enter` 确认，`Escape` 取消；同时保留正文 W/S/Z/X/A/D 阅读快捷键。数值输入使用 Enter 提交、Escape 恢复，输入和快捷键录制期间暂停空间导航。

阅读进度自动保存到每本书的 `reading-state.json`，最后阅读书籍 ID 独立保存到书库根目录的 `app-state.json`。继续阅读时先挂载视口顶部的有效块并恢复真实偏移，再由单一锚点控制器等待字体、图片解码和虚拟行稳定后完成最终校正；用户主动滚动会释放恢复锁。最后阅读状态保存失败不会阻止已解析书籍打开，书籍打开错误也不会锁住书库。树形目录高亮当前章节；书库右侧详情显示百分比和章节。进度不会改变书库最近更新排序或收藏状态。

书签独立保存到每本书的 `bookmarks.json`。默认 `C` 和书签标题右侧的 `+` 都用于切换当前位置书签：没有则添加，已有则直接取消。侧栏书签区始终显示；已有书签列出正文摘要、章节与全书百分比，点击跳转，左侧主题色按钮直接删除。直接打开开发目录时书签不持久化。

书库设置管理主题，以及“全屏”“切换书库/阅读界面”两个全局快捷键；阅读侧栏管理主题和排版与样式，完整快捷键列表使用独立窗口。两处修改的是同一组全局绑定，配置的全屏快捷键在书库和阅读界面均可使用。书库标题栏的书籍按钮与界面切换快捷键都会打开最后阅读的书，并在应用重启后恢复其持久化位置。主题按浅色、深色或系统模式只显示当前有效类型，并分别记忆亮暗主题；Calibre 夜间主题使用 `#121212` 阅读背景和 `#2d2d2d` 阅读侧栏。主题 v4 只保存 `background`、`surface`、`sidebar`、`text` 和 `accent` 五色，其余界面色由应用统一派生；书库左栏使用 `surface`，只有阅读器左右侧栏使用 `sidebar`。v1–v3 主题仍可读取并在内存中规范化。主题可通过复制 AI 提示词后从剪贴板导入。字号、注音字号、400/600/800 字重、段内间距、段落间距、栏宽、中日透明度和滚动段数即时预览并保持当前阅读块；日文引用线和进度条可关闭，纯日文引用线固定上下缩进 `0.25em`，配对日文引用线固定为顶部 `0.9em`、底部 `0.3em`，正文滚动条固定隐藏但连续滚动保持可用。出版社原生注音在辅助注音关闭时继承正文颜色，开启时使用固定金色；关闭辅助注音或片假名罗马音时不再保留撑宽汉字的注音布局。书库封面和详情的进入、退出及换书交叉淡化均为 500ms。

当前版本按 readingOrder 虚拟连续阅读，仅维护桌面端。桌面封装属于 P2。
